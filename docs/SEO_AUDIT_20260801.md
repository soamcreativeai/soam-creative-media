# SOAM MEDIA 検索流入・収益導線監査

確認日: 2026-08-01 JST

## 確認済み事実

- Google Search Consoleに `https://media.soam-creative.com/` を登録し、Google Analyticsによる所有権確認を完了した。
- `sitemap.xml` をSearch Consoleへ送信し、Google側で成功・89ページ検出を確認した。インデックス数・検索語・表示回数は新規登録のため、翌日以降に確認する。
- Googlebot向けに `robots.txt`、`sitemap.xml`、トップ、公開記事のHTTP 200を確認した。
- 公開記事82本すべてで、title、description、正規URL、Article構造化データ、著者表記、SNS共有情報を検査する自動テストをPASSした。

## 修正したこと

- 実際の公開URLは `.html` なしへ恒久的に移動するため、82記事・記事一覧・固定ページ・サイトマップの正規URLを実URLへ統一した。
- Article構造化データへ著者、運営者URL、言語、公開日、更新日を追加した。
- 記事ごとにSNS共有用のtitle、description、URLを追加し、今後の自動公開でも同じ内容が付くようにした。
- 著者表記 `執筆・編集：SOAM MEDIA` を各記事へ表示し、構造化データと本文上の表記を一致させた。
- トップに運営者の構造化データを追加し、サイト名と運営元の理解を補強した。
- お問い合わせ・プライバシーポリシー・AI診断ページをサイトマップへ追加した。保存ページ、未公開診断、管理デモは検索結果に出さない方針を維持した。

## 収益化記事の作成原則

- 記事は読者の課題・検索意図を先に定め、役割別の実務手順、向く人・向かない人、確認方法を具体的に示す。
- アフィリエイトリンクは、記事テーマに適合し、実際に有効な案件だけを最大2件まで置く。広告であることを明示し、料金・仕様・成果を断定しない。
- 実体験・検証・公式資料がない商品レビュー、順位付け、比較結果は作らない。公式情報を確認した日と確認範囲を記録できる内容だけを収益記事にする。
- 同じ意図の記事を量産せず、関連記事で次の課題へ案内する。検索順位のためだけの大量生成はしない。
