# ChatGPTへの相談文｜SOAM MEDIAの次の戦略

以下の「現状資料」を前提に、SOAM MEDIAを検索・信頼・収益・SOAM Linkへの自然な接続まで成立させるための、最も戦略的で現在有効な方針を設計してください。

## あなたに求める役割

一般的なSEOチェックリストではなく、事業・編集・収益導線を一体で設計するストラテジストとして答えてください。AI生成記事を量産するだけのメディアから、読者に選ばれ、長期的に検索され、SOAM Linkにも自然につながるメディアへ変える戦略が必要です。

## 前提として守ること

- 存在しない利用体験、レビュー、実績、利用者の声、数値、商品仕様は作らない。
- 試していない商品を「レビュー」と呼ばない。商品を勧める場合は、公式情報・確認日・向く人・向かない人を示せる範囲に限る。
- AIは整理・下書き・候補出しを担うが、公開・契約・購入・紹介・最終判断は人が行う。AIに丸投げする思想にしない。
- SOAM Linkは、読者が必要な商品・サービス・協力先を検討する段階の受け皿である。まだ提供していない機能や実績は表現しない。
- MimiとRami、TripPass、SOAM Start、SOAM Linkの各サービスそのものを、この相談の中で作り変えない。SOAM MEDIAがそれらに通底する思想をどう伝えるかだけを扱う。
- 小手先の検索順位対策ではなく、読者に役立つ独自性・一次性・信頼・継続的な収益を優先する。

## さわむー／SOAM CREATIVEに共通する思想

SOAM MEDIAで最も伝えたい独自性は、次です。

1. 感覚でしかできなかった仕事や判断を、誰でも実行できる形に分解して渡す。
2. 本人の努力不足ではなく、一人で記憶・整理・判断を抱え続ける構造が重いと捉える。仕組みで負担を軽くする。
3. AIは人の代わりに重要な決定をする存在ではない。情報を整理し、候補を出し、本人が納得して選べる状態を作る。
4. 「AIで何ができるか」から始めず、「今、誰が何に困っているか」から現場で設計する。
5. 作って終わりではなく、小さく動かし、実際の課題を見つけ、改善を続ける。
6. 良い商品・サービスが必要な人に届くこと、紹介する人・掲載する人・選ぶ人が納得できることを大切にする。

## 回答してほしいこと

次の順で、曖昧な表現を避けて提案してください。

1. **SOAM MEDIAの勝てる主題**
   - 誰の、どんな困りごとに最も強いメディアに絞るべきか。
   - 現在の広いカテゴリを、何を主軸・補助・縮小対象に分けるべきか。
   - この思想が読者に一言で伝わる、サイトの約束・説明文の案。

2. **記事をAI一般論から抜け出させる編集モデル**
   - 既存記事をどう分類し、どのタイプから書き直すか。
   - 1記事に必要な構成、具体例、判断表、テンプレート、出典、更新のあり方。
   - 実体験を捏造せずに「SOAMならではの深さ」を作る材料の集め方。
   - AIが作成しても公開に値しない記事を止める、具体的な基準。

3. **SOAM Linkとの接続設計**
   - SOAM MEDIAとSOAM Linkの役割分担。
   - どんな記事の、どの瞬間に、どんな言葉で案内すれば押し売りにならないか。
   - 将来、掲載者の商品を扱う際の「課題記事 → 判断支援 → 紹介」の設計。

4. **最初の90日で行う順番**
   - 最優先で作り直す記事群・新設すべきハブ記事・固定ページ。
   - 1日3本の自動公開を、量ではなく品質と成果に変えるための配分。
   - 週次・月次で見るべき数字と、数字が出た後の判断ルール。

5. **避けるべきこと**
   - Googleにも読者にも弱くなる量産、広告、記事構成、導線、表現。
   - 「最先端SEO」と称されがちだが、SOAMには採用しない方がよい施策。

## 出力形式

- 最初に結論を3行で示す。
- 「現状の問題 → 目指す形 → 実行順」の表を必ず入れる。
- 90日計画は週単位で、具体的な成果物と判断基準を示す。
- 実装指示ではなく、まず事業・編集戦略として提案する。
- 不明な事実は推測で埋めず、「追加で必要な一次情報」として分ける。
