# SOAM CREATIVE MEDIA 紹介モデル v1

## 目的

SOAM Linkの掲載商品を、単発の広告としてではなく、読者の課題解決の文脈で紹介する。SOAM CREATIVE MEDIA自身を、将来の紹介者が参照できる編集モデルにする。

## 商品を受け取ったときの判断

掲載者から「売ってほしい」と依頼を受けても、直ちに紹介記事を公開しない。編集部は以下のいずれかを選ぶ。

1. **主役として紹介する**: 読者課題、公式情報、紹介の根拠が揃っている。
2. **関連選択肢として紹介する**: 課題には関係するが、単独記事にする根拠がまだ足りない。
3. **保留する**: 読者に役立つ説明、料金・仕様、注意点などが不足している。

## 掲載者から回収する紹介情報

- 商品・サービス名と公式URL
- 解決する課題、対象者、対象外の人
- 料金、提供範囲、導入手順、制約
- 変更されやすい情報と確認日
- 使用可能な画面・画像・デモ
- 比較対象になりうる手段
- 紹介リンクと成果条件

確認できない実績、感想、利用者数、成果は掲載材料にしない。

## 1商品を育てる記事群

| 種類 | 読者の問い | 公開条件 |
| --- | --- | --- |
| 課題記事 | 何が困りごとなのか | 具体的な業務・生活場面を説明できる |
| 紹介記事 | その商品は自分に合うか | 公式情報、対象外、確認日が揃う |
| 比較記事 | 他の方法とどう違うか | 比較基準と各選択肢の根拠がある |
| 導入記事 | 始める前に何をするか | 実演済み範囲または公式手順を明記できる |
| 更新記事 | 今も選択肢として有効か | 変更元と確認日を提示できる |

試用していないものを「レビュー」と呼ばない。公式情報を整理した記事は「選び方」「確認ポイント」として扱う。

## 1日3本の配分

| 枠 | 役割 | 比率の目安 |
| --- | --- | --- |
| 新規流入 | 課題・検索意図に答える | 1本 |
| 判断支援 | 紹介・比較・導入を深める | 1本 |
| 再訪 | 更新・既存記事の改善・テーマまとめ | 1本 |

同一商品の近い検索意図を、同日に重複させない。各記事は「何を知りたい読者か」と「次に読む記事」が異なることを公開条件にする。

## 鮮度の管理

| 記事の種類 | 見直しの基準 |
| --- | --- |
| 料金・仕様を含む紹介 | 30日ごと、または掲載者・公式の変更時 |
| 比較・選び方 | 90日ごと、または比較対象の変更時 |
| 普遍的な解説 | 180日ごと |
| キャンペーン・速報 | 終了日または変更時に更新・非表示判断 |

公開画面へ「更新」を表示するのは、確認日と情報源を記録できる場合だけとする。

## 読者導線と計測する指標

`検索記事 → 関連記事 → 紹介リンク → 成果確認`

- 次の記事への遷移率
- 保存・共有の利用数
- 紹介リンクのクリック率
- 承認済み成果に至った割合

成果データがSOAM Linkと接続されるまでは、成果を示す表示を記事側に作らない。
